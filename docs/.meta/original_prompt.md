使用Go语言实现一个分布式高可用智能爬虫集群与可视化规则提取平台（Mini Scrapy Cloud）

业务背景：不仅是一个爬虫，而是一个可以通过 Web 界面管理多个爬虫节点、在线点击网页元素自动生成爬取规则、并支持分布式去重的综合大数据平台。

前端页面 (Vue 3 + Chrome DevTools 协议嵌入)：可视化规则配置器：在前端内嵌一个目标网页，用户用鼠标点击某个标题或价格，前端自动计算出对应的 XPath/CSS 选择器，并保存为爬取规则。集群监控大屏：监控各个 Node 节点的 CPU、内存、当前爬取速率（Pages/Min）和失败率。

Go 后端核心实现：Master-Worker 调度架构：Master 负责任务队列切分（如按 URL 哈希），通过 gRPC 动态分发给多个爬虫 Worker 节点。分布式布隆过滤器 (Bloom Filter)：基于 Redis 位图实现海量 URL 的分布式去重，防止重复爬取。动态解析引擎：后端加载用户配置的 XPath/Regex 规则，流式解析 HTML，支持代理 IP 池自动轮询与限速抗封锁。

文件数与代码量：约 40+ 个 Go 文件，代码量 8000 - 10000 行。
